# Blinkling 3.0.1

A small fix release for 3.0.0.

- macOS: the Ctrl pick key needs the Accessibility permission, which the first run never asked for, so on a Mac the pick could silently do nothing. Blinkling now raises the system prompt once and starts listening for the key as soon as you allow it, with no restart. The README, the install guide and `docs/INSTALL.md` say so.
- Guide mode failure and closing bubbles follow the system language in all nine languages. They were fixed Traditional Chinese for everyone.
- The Full page chip falls back to the visible part of the window when the page grab fails. The attachment is now named Visible part, so it is not mistaken for the whole page.

The four desktop builds keep the names used by 3.0.0, with the version changed to 3.0.1. The plugin pins each build by SHA-256 and size.

See the [install guide](https://github.com/Arthur031221/Blinkling/blob/v3.0.1/docs/INSTALL.md) for the manual route.
