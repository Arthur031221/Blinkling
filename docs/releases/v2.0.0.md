# Glimpselet 2.0.0

Glimpselet now runs in a Chromium extension with a floating chat that stays visible while you work in another tab or app. Float is the first action. Screen sharing starts inside the bubble, and compact mode keeps sharing alive.

Crop freezes a shared screen and opens a full screen selector with handles, pixel dimensions, keyboard adjustment, Enter and Esc. Holding Shift starts selection on a web page or shared screen. The bubble contents fade during selection. A browser shortcut and a remappable global shortcut are included.

An optional Claude Code channel delivers bubble questions into the running terminal conversation and streams scoped replies back. It requires the documented preview channel setup. Without it, choose an exact recent session for a clearly labelled parallel continuation or start a dedicated conversation.

The chat supports streamed replies, follow ups, model and effort choices, copy, pin and Stop. Capture a visible tab, full page or element. Use Guide to draw around real page controls. Suggested questions, optional passive summaries, reversible page translation, text selection actions and a bundled PDF reader are included.

The bilingual welcome page detects pairing, supplies an SSH tunnel command for a remote host and provides an eight step practice tour. A local desktop can try a dedicated Chromium profile without browser installation clicks. Standard installation copies the extension to `~/.glimpselet/extension`. Store listing URLs in one configuration file choose the store flow after approval.

The release includes the extension ZIP, an updated browser recorded demo and Chrome and Edge submission assets. The account holder submits the store listings. No telemetry is collected. Captures stay in memory. Preferences and credentials have documented storage scopes.

Desktop Chromium browsers are required. Unpacked extensions have a developer mode banner and need manual updates. Protected pages cannot be scripted, PDFs use the Glimpselet reader, and native apps support screen questions rather than page drawings. PiP placement, automatic opening and native click through are browser limitations. See [Design](../DESIGN.md), [installation](../INSTALL.md) and [store preparation](../STORE.md).
