# Blinkling 3.0.0

Blink now lives on your desktop. It is a small companion window that sits beside whatever you are doing and talks to your own Claude Code session.

Install it from Claude Code with one pasted line, then run `/blinkling:blinkling`. On macOS, allow the screen permission once when it asks. The [install guide](https://arthur031221.github.io/Blinkling/install/) picks your system and shows only its steps, with a short animation for each action.

The release carries four desktop builds, named by system: `Blinkling-3.0.0-mac-arm64.zip`, `Blinkling-3.0.0-mac-x64.zip`, `Blinkling-3.0.0-win-x64.exe` and `Blinkling-3.0.0-linux-x64.AppImage`. The plugin pins each build by SHA-256 and size and refuses anything else, so it never runs a download it did not expect. `SHA256SUMS` lists the same digests.

- On Ubuntu 24.04 and other systems that restrict unprivileged user namespaces, Blink now starts without manual steps. It uses the Chromium sandbox whenever the system allows one and falls back to running without it only when neither a user namespace nor a setuid helper is available.
- The plugin finds the build whether the repository is reached as Blinkling or by its old Glimpselet address.
- `startWithClaudeCode=false` is honored: Blink stays closed when Claude Code starts.
- `BLINKLING_REMOTE=0` skips the Remote Control request for automated runs.
- The plugin, the desktop app and the root package all report 3.0.0, and the two install scripts read the same default repository.

macOS builds are ad-hoc signed, not notarized, and Windows builds are unsigned. If macOS shows "cannot be opened" or Windows SmartScreen warns, the install guide shows the short steps to allow Blinkling.

See the [install guide](https://github.com/Arthur031221/Blinkling/blob/v3.0.0/docs/INSTALL.md) for the manual route.
