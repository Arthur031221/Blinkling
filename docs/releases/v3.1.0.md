# Blinkling 3.1.0

A new Blink, a smoother pick and a sturdier connection to the command line tool.

- Blink is new, and smaller. Held, it trembles and its legs dangle. Swung round in two full circles, it gets dizzy. Touching its head, cheeks, belly, hands or feet each gets a different reaction, and after a quiet minute it thinks out loud in one of eight short lines in your language. The logo, the app and browser helper icons, the permission page, the demo recordings, the store images and the social card all show the new Blink.
- The Ctrl pick keeps going while the key stays held: captures pile up, the auto box morphs into the dragged rectangle, text is marked with a highlighter stroke, and on release the captures are sucked into Blink's mouth. The quick box keeps every capture and a thumbnail opens the full image. The hint no longer runs off the right edge of the screen.
- The quick box and the chat card share one toolbar with a file button and lists for model, effort and permission, and both are anchored to Blink's mouth.
- Typed messages now get an answer or a visible reason. Command line tool builds 2.1.296 and later in the 2.1 line are accepted, the command is found even when the app was opened from the Dock, and a message typed in the linked web or phone session shows up in Blink too.
- macOS: the pick key no longer shares Blink's main thread, which froze Blink with input methods such as Zhuyin. Keys come from a small separate helper. This fix could not be tried on a real Mac here, only through the automated tests.
- Close joins the menu as a fifth bubble and always quits. Screenshot takes the largest area you can see in one click. Settings has a Language row with all nine languages, and so does the install page.

The four desktop builds keep the names used by 3.0.0, with the version changed to 3.1.0. The plugin pins each build by SHA-256 and size.

See the [install guide](https://github.com/Arthur031221/Blinkling/blob/v3.1.0/docs/INSTALL.md) for the manual route.
