# Glimpselet 2.1.0

The floating bubble now fades when idle, becomes clearer on hover and returns to full opacity while typing or answering. A compact Blink control, edge placement and saved window position keep it nearby while leaving more of the page visible. DOM overlays let clicks reach uncovered content; the browser-owned floating window still has native limits.

Capture whole screen, Pick an area and Guide this page are the three primary actions. Auto explain combines automatic questions and summaries, limits suggestions to three and uses short structured answers, including readable Chinese, Japanese and Korean formatting. Page changes can be summarized without screen sharing. Shared monitors and apps require separate consent for each share; the bubble is masked in monitor frames and unchanged frames are ignored. Additional capture and translation tools remain available in the menu.

Capture requests access at the point of use. Shared-screen capture clears the floating window and restores it automatically, by minimizing or closing the native surface. Cropping keeps keyboard cancellation and cross-display geometry. When Escape consumes the browser gesture needed to reopen a floating window, a companion popup preserves the chat and offers a button to restore floating mode.

Guide this page covers reading regions and paragraphs as well as controls. Start with an annotated overview, then use Next and Back to tour the page. Scrolling or resizing a background guide does not take focus from another app. Page collection is bounded, so unusually large or dynamic pages may need another guide request.

The welcome guide has three steps in all nine languages: install, connect and open the bubble. The second consent screen and practice exercises have been removed. Standard installation uses the visible `~/Glimpselet-extension` folder, and browser connection is automatic. Local desktops can still try Glimpselet without installing; remote hosts retain the SSH tunnel flow.

Glimpselet uses a live Claude Code channel when available, otherwise it resumes the latest conversation in the current project. The channel requires the documented opt-in startup flag. A session continuation does not inject messages into an already running terminal.

The plugin, bridge and extension are all version 2.1.0. The release includes the extension ZIP and Chrome and Edge submission kits; the account holder submits the store listings. Automatic page summaries retain password, blocklist and embedded-page restrictions. Shared browser tabs must remain bound to the inspected tab. Monitor and app images cannot be checked for sensitive fields, and unknown sharing sources stay paused. Browser rules still limit native window opacity, click-through, placement and focus restoration. See the [install guide](../INSTALL.md), [design notes](../DESIGN.md) and [store preparation](../STORE.md).

All nine READMEs have a new layout, a three-step install and real extension recordings: Google Flights with a guide and a booking question, and an arXiv abstract with select-to-ask and translation. The recordings use live Claude Code replies; waiting time is shortened.
