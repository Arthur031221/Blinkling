# Features

Every Blinkling feature, in one table. Tier **main** is the whole product for most people and the only thing the welcome teaches. **secondary** is kept but quiet. **removed** is gone from the code, the settings, the locale strings and the docs.

`scripts/features.test.mjs` checks this file against the repository: every main and secondary entry point must exist, the menu rows must match `menuActions` in `desktop/menu/index.mjs` one for one and each menu action must have a handler in the action registry, and every symbol named in a removed row must be absent everywhere except `CHANGELOG.md`. Entry points are written as `path`, `path::literal` (a file that must contain the literal), `command:name` (`commands/name.md`) or `tool:name` (an MCP tool in `bridge/src/server.ts`).
