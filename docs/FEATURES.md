# Features

One table of every feature. The tier says how loudly it shows up: **main** is the whole product for most people and the only thing the welcome teaches, **secondary** is kept but quiet, and **removed** is gone from the code, settings, strings, docs and tests. `scripts/features.test.mjs` checks every main and secondary entry point exists and every removed row's symbols are gone from the repository (the CHANGELOG is history and is exempt).

Entry points are written as `kind:value`: `file:` a path, `menu:` a menu action id, `command:` a slash command, `tool:` an MCP tool, `symbol:` a name inside a file (`path#name`), `setting:` a key inside a file (`path#key`), and `gone:` a name that must not appear anywhere.

| Feature                             | Tier      | Entry point                                                                                                  | Why                                                                                                  |
| ----------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| Blink in the corner                 | main      | `file:desktop/character/index.mjs` `file:desktop/main/shell.mjs`                                             | The product itself: a small companion that is always near the screen it helps with.                  |
| Ask about what is under the pointer | main      | `file:desktop/capture/selection.mjs` `file:desktop/capture/integration.mjs`                                  | One gesture takes a thing, an area or a window, so there is one thing to learn.                      |
| Mini composer                       | main      | `file:desktop/composer/index.mjs` `file:desktop/composer/index.html`                                         | What was taken flies into Blink and the question starts right there.                                 |
| Answers as bubbles that point       | main      | `file:desktop/messages/index.mjs` `file:desktop/overlay/index.mjs`                                           | The answer comes from Blink and marks what it talks about on the real screen.                        |
| Capture menu                        | secondary | `menu:settings` `file:desktop/menu/index.mjs`                                                                | A mouse-only way to the same capture, quiet until the pointer rests on Blink.                        |
| Guide mode                          | secondary | `menu:guide` `file:desktop/overlay/guide.mjs`                                                                | Numbered marks for a procedure, drawn by the same pointing engine as answers.                        |
| Auto explain                        | secondary | `menu:auto-explain` `file:desktop/autowatch/index.mjs`                                                       | Off by default; a short note when the screen changes a lot.                                          |
| Settings                            | secondary | `menu:settings`                                                                                              | The few real choices, in one place.                                                                  |
| Browser helper status popup         | secondary | `file:extension/popup.html` `file:extension/popup.ts` `file:extension/manifest.json`                         | A quiet helper: one line each for what is connected or missing, and a Wake Blink button.             |
| Page structure for the locator      | secondary | `symbol:plugin/desktop/host.mjs#elements` `file:extension/elements.ts`                                       | The browser knows what each element is; password and secure fields come back with no text.           |
| Full-length page capture            | secondary | `symbol:plugin/desktop/host.mjs#fullPage` `file:extension/full-page.ts` `file:desktop/capture/full-page.mjs` | The browser can scroll and stitch the whole page, which a screenshot cannot.                         |
| Translate in place                  | secondary | `symbol:plugin/desktop/host.mjs#translatePage` `file:extension/translate.ts`                                 | Translates the live page with a toggle back, only when the pick is a whole web page.                 |
| PDF reader                          | secondary | `symbol:plugin/desktop/host.mjs#openPdfReader` `file:extension/reader.html`                                  | The browser's PDF viewer exposes no text, so the helper opens the file in its own reader.            |
| Claude Code commands                | secondary | `command:blinkling` `command:install` `command:look` `command:watch`                                         | Wake Blink, set up the helper, or look at the screen from the terminal.                              |
| Screen tools for Claude             | secondary | `tool:desktop_open` `tool:extension_install` `tool:screen_capture` `tool:screen_latest`                      | Claude Code asks for a capture only when the user asks, and keeps nothing for long.                  |
| Floating chat in the browser        | removed   | `gone:documentPictureInPicture`                                                                              | Blink on the desktop replaced the pill, the chat window and the passive summary card.                |
| Per-page suggested questions        | removed   | `gone:parseSuggestions` `gone:loadPageAnalysis`                                                              | The quick-ask chips cover it without a model call for every page.                                    |
| Select-to-ask popover               | removed   | `gone:selectionPopover`                                                                                      | Selecting text and pressing the pick key does the same in every app, without clutter on pages.       |
| SSH tunnel and pairing codes        | removed   | `gone:ssh -L` `gone:pairingCode`                                                                             | Blinkling runs on the computer with the screen; the helper pairs on its own and nobody types a code. |
| API key mode                        | removed   | `gone:apiMode` `gone:x-api-key`                                                                              | Claude Code installed on this computer does the work; a missing install gets one explaining bubble.  |
| Zero-install browser window         | removed   | `gone:launch-browser`                                                                                        | The desktop app needs no browser.                                                                    |
| Extension-first welcome and tour    | removed   | `gone:Try without installing` `gone:不安裝`                                                                  | The companion has its own guide, shown only when a feature that needs it is used.                    |
