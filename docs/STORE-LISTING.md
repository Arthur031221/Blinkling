# Store listing copy

## Chrome Web Store

**Name:** Glimpselet

**Short description:** Ask about a page you choose to share, with a compact floating chat beside it.

**Category:** Productivity

**Privacy policy:** https://arthur031221.github.io/Glimpselet/privacy.html

**Single purpose:** Glimpselet helps users understand browser pages they choose to share by answering questions in a floating chat and guiding them to page controls.

**Description:** Glimpselet is a browser companion for understanding a page you choose to share. Open it with Alt+Shift+G, keep its chat in a floating window, and ask a question about the visible page. Capture a visible tab, full page, selected region, element, or a screen selected in the browser picker. Page tools can explain selected text, translate eligible page text, and guide you to controls. You choose when to share page context or an image. Optional passive summaries are off until enabled. Connect to a local command-line assistant through the companion bridge or use direct API mode with your own key. Glimpselet has no telemetry.
