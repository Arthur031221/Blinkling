Install

You need Claude Code, signed in. Then it is one pasted line, one command, and on a Mac one permission.

Which computer do you have?

We picked this from your browser. Not sure? Apple menu, About This Mac: “Chip” says Apple M…, “Processor” says Intel.

Pick your computer above to see its steps.

Steps for a Mac

  1. 1

    Paste this line into Terminal and press Return.

    claude plugin marketplace add Arthur031221/Blinkling && claude plugin install blinkling@blinkling
    Terminal

    $ claude plugin marketplace add Arthur031221/Blinkling && …

    Added marketplace blinkling

    Installed blinkling@blinkling

  2. 2

    Start Claude Code with this line, then type /blinkling:blinkling. Blink appears.

    The flag lets Blink's chat reach this session. Claude Code asks you to confirm it once. Without it Blink still works and answers from its own session.

    claude --dangerously-load-development-channels plugin:blinkling@blinkling
    Claude Code

    > /blinkling:blinkling

  3. 3

    Allow Screen Recording once: switch on Blinkling in System Settings, Privacy & Security. macOS also asks for Accessibility so the Ctrl key works. Allow it the same way.

    Screen & System Audio Recording
    Blinkling

If macOS still says it cannot open Blinkling

Blinkling is not notarized by Apple. Normally nothing is asked. If it is, open System Settings, Privacy & Security and choose Open Anyway.

“Blinkling” can’t be opened

Apple could not check it for malware.

Done

Open Anyway

If Windows says it protected your PC

Blinkling is not signed with a paid certificate, so SmartScreen may ask. Choose More info, then Run anyway.
