# Glimpselet

Glimpselet は他のウィンドウより前面に表示され、既存の Claude Code セッションに接続する小さなチャットです。アクセス可能なウェブページの読み取りや翻訳、実際のページ上へのガイド描画、ページ範囲や共有画面のキャプチャを使った質問ができます。

![Glimpselet のフローティングチャット](assets/demo.gif)

![実際のページ上に描かれたガイドサークル](assets/screenshots/guide.png)

[静的デモを開く](https://arthur031221.github.io/Glimpselet/)。サンプル画像と録画済みの回答を使い、サービスへのリクエストは行いません。

## インストール

Claude Code に Glimpselet プラグインをインストールします。

```text
/plugin marketplace add Arthur031221/Glimpselet
/plugin install glimpselet@glimpselet
```

`/glimpse` を実行し、セットアップガイドに従ってください。インストールとペアリングの手順はこのガイドを参照してください。

### 詳細: ソースから読み込む

1. Chrome または Edge で `chrome://extensions` を開き、**デベロッパーモード**を有効にします。
2. **パッケージ化されていない拡張機能を読み込む**を選びます。
3. セットアップガイドに示された拡張機能フォルダーを選択します。

> **デベロッパーモード:** Glimpselet は現在デベロッパーモードで配布されています。ストアに掲載されるまでは、更新を手動でインストールする必要があります。

## キャプチャとショートカット

フローティングバブルまたはアクセス可能なウェブページ上で Shift を押し続けると、範囲選択が始まります。Shift キーは他のアプリでは検知できません。ウェブページでは表示中のページ上で選択します。画面共有中はフレームを静止させ、全画面で切り抜きます。Enter で確定、Esc でキャンセルします。

ブラウザー内で切り抜きを始めるショートカットは Ctrl+Shift+S（Mac は Cmd+Shift+S）です。別のグローバルショートカットは Ctrl+Shift+7 が初期値です。Chrome のグローバルショートカットには数字キーが必要です。`chrome://extensions/shortcuts` で変更でき、S に割り当てることもできます。

## Claude Code セッション

ドキュメント化された MCP channel の機能を使うと、実行中の Claude Code セッションにメッセージを送れます。Glimpselet は reply ツールのチャンクから返答を表示します。モデルと権限はターミナル側のセッションが管理します。Glimpselet 独自の channel を追加するには、開発用 channel を有効にしてセッションを再起動し、`/glimpse` を実行してください。

```sh
claude --resume SESSION_ID --dangerously-load-development-channels plugin:glimpselet@glimpselet
```

channel を使わない場合、別の print モードプロセスで `claude --resume SESSION_ID -p` を実行して同じセッションを続けられます。これは並行した続行です。同じセッションを使うターミナルプロセスと同時に実行すると競合する可能性があります。

## 制限

- Chrome、Edge、その他の Chromium ブラウザーに対応します。
- `chrome://` などのブラウザー内部ページ、拡張機能ストア、一部の管理対象ページではアクセスできません。
- ネイティブアプリには描画できません。画面を共有して画像について質問できますが、ページ上のオーバーレイやテキスト操作は使えません。
- PDF は付属の Glimpselet リーダーで開いてください。Chrome 内蔵 PDF ビューアーはアクセス可能なウェブページではありません。
- ブラウザーの Document Picture-in-Picture API はクリック透過に対応していないため、フローティングウィンドウから他のアプリへクリックを通せません。フローティングウィンドウや自動ポップアウトも保証されません。使用中は拡張機能ページを開いたままにしてください。

## プライバシー

テレメトリーはありません。同意後、提案する質問を作るためにページテキストが送信されることがあります。質問や任意のパッシブ要約でも、関連するテキストと画像が送信される場合があります。フレームはメモリー上に保持され、キャプチャまたは質問のリクエスト時にのみブリッジへ送信されます。ブリッジモードではホスト上で CLI が動作し、セッション記録もホストに保存されます。直接 API モードでは拡張機能からリクエストを送ります。API キーとブリッジトークンはブラウザーのセッションストレージに保存されます。設定はローカルストレージに保存されます。詳しくは[セキュリティとプライバシー](docs/SECURITY.md)をご覧ください。
