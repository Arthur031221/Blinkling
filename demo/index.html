A floating Claude Code chat for what you're reading. Capture an area, ask a follow-up, or follow a guide through the page.

Get started

Desktop Chrome or Edge. Your Claude Code login. No publisher server.

Three actions

Start with Claude Code.

  1. Paste one line

    In a terminal, with Claude Code signed in:

    claude plugin marketplace add Arthur031221/Blinkling && claude plugin install blinkling@blinkling

  2. Run one command

    /blinkling:blinkling

    Blink appears on your desktop.

  3. Allow Screen Recording

    On a Mac, switch on Blinkling once in System Settings, Privacy & Security.

Store listings are not available yet. Blinkling installs from GitHub through Claude Code. Updates are manual. Open the install guide for your computer, with animated steps.

While you read

Ask, point, translate.

Capture and ask

Hold Shift and drag on a supported page, or crop a shared screen in full screen. The capture lands in the bubble for your next question.

Find your way

Get a page overview, then follow Next and Back through reading regions, sections and controls.

Read across languages

Translate page text in place and restore the original. Select a passage to explain, translate or ask. PDFs open in the Blinkling reader.

Keep the conversation

Get suggested questions and streamed follow-ups. Enable the channel preview to talk to your running terminal session. Otherwise, continue the latest saved project conversation in a separate process. Auto explain is optional.

These recordings use the real extension on live Google Flights and arXiv pages with Claude Code replies. Waiting time is shortened. The separate prerecorded chat makes no provider calls.

A few limits, up front.

Desktop Chromium browsers only. Browser settings and extension stores block page tools. Native apps support screen capture and chat, while guides and in-place translation need a web page. PDFs use the bundled reader. The floating window cannot pass clicks through.

Page context is used after consent. Suggested questions can send page text automatically. Auto explain pauses on password fields, blocked sites and inaccessible embedded pages. Shared monitors and apps need separate consent for each share because those pixels cannot be checked for sensitive fields. Unknown sources remain paused. Your selected provider's terms apply.
