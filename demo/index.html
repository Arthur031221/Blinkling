Three steps

Start with Claude Code.

  1. Add the plugin

    In your signed-in Claude Code terminal:

    /plugin marketplace add Arthur031221/Glimpselet
/plugin install glimpselet@glimpselet

  2. Open the welcome guide

    /glimpselet:glimpse

    It walks you through the browser connection in Chinese or English.

  3. Choose your browser

    Try a dedicated Chromium window on a local desktop, or load the extension in your own browser. If Claude Code is remote, run the guide's SSH command on the computer with Chrome.

Store listings are not available yet. The welcome guide uses Developer mode and Load unpacked today. Updates are manual. Read the install guide.

While you read

Ask, point, translate.

Capture and ask

Hold Shift and drag on a supported page, or crop a shared screen in full screen. The capture lands in the bubble for your next question.

Find your way

Ask where a control is. Guide mode circles real page elements and adds a short note beside them.

Read across languages

Translate page text in place and restore the original. Select a passage to explain, translate or ask. PDFs open in the Glimpselet reader.

Keep the conversation

Get suggested questions and streamed follow-ups. Enable the channel preview to talk to your running terminal session, or use a dedicated conversation. Passive summaries are optional.

These recordings use the real extension on a public GitHub page with local example replies. The prerecorded chat makes no provider calls.

A few limits, up front.

Desktop Chromium browsers only. Browser settings and extension stores block page tools. Native apps support screen capture and chat, while guides and in-place translation need a web page. PDFs use the bundled reader. The floating window cannot pass clicks through.

Page context is used after consent. Suggested questions can send page text automatically. Passive summaries are opt-in and pause for whole screens, native windows and unknown sources. Your selected provider's terms apply. Read what is sent and stored.
